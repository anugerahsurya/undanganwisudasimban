# Audit panel Google Sheets admin

Tanggal: 17 September 2026.
Mode: setelah implementasi, sesuai pilihan pengguna. Temuan tidak diperbaiki tanpa persetujuan nomor temuan.
Lingkup: perubahan admin.js, admin.css, dan integrasi Apps Script; bukan desain ulang undangan publik.

## Temuan

1. **HIGH, R-02:** teks status awal di `assets/js/admin.js` menggunakan em dash pada “Mode lokal”. Ganti dengan titik atau titik dua.
2. **HIGH, R-25:** tombol panel mewarisi `.btn-template:hover` dengan teks putih di atas `#b8860b`. Kontras terhitung **3,25:1**, di bawah minimum 4,5:1 untuk teks normal. Gunakan warna hover lebih gelap atau teks gelap.
3. **HIGH, R-27:** koneksi awal, muat ulang, dan hapus menonaktifkan kontrol selama permintaan, tetapi belum menampilkan teks proses khusus masing-masing aksi. Impor sudah menampilkan progres pengiriman. Tambahkan status proses untuk aksi lainnya.
4. **HIGH, R-03/R-35:** tampilan responsif, keyboard, fokus setelah render ulang, unduhan aktual, serta seluruh tombol belum diuji di browser nyata. Tes DOM tiruan bukan bukti kelulusan visual atau CORS. Uji pada lebar 320, 375, 768, dan 1280 piksel, termasuk pesan kesalahan panjang.
5. **LOW, R-31/R-37:** tidak ada Design Read yang dicatat sebelum implementasi. Panel menggunakan tipografi, warna burgundy/emas, dan komponen yang sudah ada; tidak ada arah visual baru yang disepakati.

## Alasan komposisi yang dipakai

- Warna dan font diwarisi dari admin untuk menjaga konsistensi, bukan menambah identitas visual baru.
- Form koneksi di atas daftar memisahkan pengaturan sumber data dari input tamu.
- Satu panel menampung status dan migrasi agar admin dapat membedakan data lokal dan Spreadsheet.
- Grid form menjadi satu kolom pada layar kecil; tombol migrasi membungkus dan memiliki tinggi minimum 44 piksel.
- Status memiliki teks persisten dan warna kesalahan; angka berasal dari data atau respons API, bukan angka promosi.
- Tidak ada ilustrasi, logo, avatar, atau klaim pemasaran baru.

### Interaksi yang diuji dengan simulasi

- Hubungkan: daftar server dimuat; data lokal tidak diimpor otomatis.
- Impor: kode identik dilewati; kode dan tautan dipertahankan; cadangan dibuat.
- Impor menunggu server: kontrol dinonaktifkan; tidak mengklaim tersimpan sebelum konfirmasi.
- Respons hilang: data lokal tetap tersedia; pengiriman ulang tidak menduplikasi.
- Impor 501 tamu dengan batch kedua gagal: 500 tersimpan di simulasi, 1 tetap lokal.
- Tambah manual: staging lokal lalu simpan server; input dikosongkan setelah staging.
- Kosongkan: hanya tamu yang sudah dimuat dihapus; tamu baru dari sesi lain dipertahankan.
- Token salah, benturan kode, batch berlebih: ditolak backend.
- JSON rusak dan quota storage: tidak direset diam-diam; input yang belum tersimpan dipertahankan.
